## **What is Version Control?**
version control is the practice of tracking and managing changes to software code.
## **What is Git?**
Git is a open source software version control software that runs locally on computer.
## **What is GitHub?**
GitHub is a online platform where developers can store,manage and share their codes.
## **What is Git Bash?**
Its a software application for Microsoft windows that enables users to run Git commands.
## **What are the main parts of GitHub?**
The main parts of GitHub are Repositories. 
## **What are the stages of Git/GitHub?**
There are 3 main stages of Git/GitHub:
1. Working directory
2. Staging area and
3. Local repository
